# Card

A surface that groups things that belong together. It is not a container for a whole
page, and nesting one card in another is always a layout problem wearing a component.

## Import

```tsx
import { Card, CardHeader, CardBody } from "@acme/ui/card";
```

## Usage

```tsx
<Card elevated>
    <CardHeader>Billing</CardHeader>
    <CardBody>Your plan renews on the 4th.</CardBody>
</Card>
```

`elevated` is for a card that floats above the page — a summary pinned over a list.
A card sitting in the page flow stays flat.

## Notes

- `CardHeader` renders a `<header>` and `CardBody` a `<div>`; neither adds a heading
  level, so put a real `<h2>`/`<h3>` inside the header when the card has a title.
- There is no `CardFooter`. Actions go in the body, right-aligned by the page layout.
