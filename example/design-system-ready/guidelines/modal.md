# Modal

A window that interrupts. Use it for a decision that must happen before anything
else — never for a form a person may want to leave open, and never for content they
might want to read beside the page behind it.

## Import

```tsx
import { Modal } from "@acme/ui/modal";
```

## Usage

```tsx
<Modal isOpen={isOpen} onClose={close} title="Delete workspace">
    This removes every project in it. There is no undo.
</Modal>
```

The `title` is the accessible name of the dialog, so it is a required prop and it is
read out before anything inside. `onClose` is called by the close control and by the
Escape key; a modal that cannot be dismissed is not built with this component.

## Notes

- Rendering is all-or-nothing: `isOpen={false}` renders nothing at all, so state
  inside a modal does not survive a close.
- There is no drawer or sheet variant. See [GAPS.md](../GAPS.md).

### Keyboard and accessibility

**Role:** dialog · **Accessible name:** The `title` prop, which is required.

| Key | What happens |
| :-- | :-- |
| `Escape` | Calls onClose |
| `Tab / Shift+Tab` | Cycles inside the dialog and does not leave it |

**Focus.** Moves into the dialog on open and returns to the control that opened it on close.

The page behind is inert while it is open. A modal that does not trap focus is a bug, not a variant.
