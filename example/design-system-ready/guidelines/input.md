# Input

A single-line text field with its label. The label is a required prop, not a
decision — a field without one is unbuildable in this system on purpose.

## Import

```tsx
import { Input } from "@acme/ui/input";
```

## Usage

```tsx
<Input label="Work email" hint="We only use this for billing receipts." />
```

Error state:

```tsx
<Input label="Work email" isInvalid hint="That address is already in use." />
```

`isInvalid` sets `aria-invalid` and re-colours the field. The `hint` slot carries both
the helper text and the error message, so a person reading with a screen reader hears
the reason rather than only the state.

## Notes

- There is no `Textarea` and no `Select` in this system yet; both are listed in
  [GAPS.md](../GAPS.md).
- Every native `<input>` prop passes through, `type`, `required` and `autoComplete`
  included.

### Keyboard and accessibility

**Role:** textbox · **Accessible name:** The `label` prop, which is required.

| Key | What happens |
| :-- | :-- |
| `Tab` | Moves to it |
| `Escape` | Nothing — this is not a combobox |

**Focus.** Native. Focus stays on the field when `isInvalid` turns on.

`hint` is wired to the field, so a screen reader reads the error with the field rather than after it.
