# Table

A table of records a person reads across, and sorts. Not a layout grid: if the
columns are not the same kind of thing in every row, it is a list, not a table.

## Import

```tsx
import { Table, TableRow, TableCell } from "@acme/ui/table";
```

## Usage

```tsx
<Table density="compact">
    <TableRow>
        <TableCell>Acme Ltd</TableCell>
        <TableCell>Active</TableCell>
    </TableRow>
</Table>
```

`density="compact"` is for a table someone scans for one row among hundreds.
`comfortable`, the default, is for tables people read.

## Notes

- The header row is a `TableRow` of `<th>` elements you write yourself; this system
  does not ship a `TableHeader`, and it is in [GAPS.md](../GAPS.md).
- Pagination, sorting and selection are the page's job. The
  [list page pattern](patterns/list-page.md) has the full skeleton.

### Keyboard and accessibility

**Role:** table · **Accessible name:** Give it a `<caption>`, or an `aria-label` when the heading above it already says what it is.

| Key | What happens |
| :-- | :-- |
| `Tab` | Moves through the interactive cells only, not through every cell |

**Focus.** Cells are not focusable. Controls inside them are.

Sorting controls are buttons in the header cells and must carry `aria-sort` on the cell.
