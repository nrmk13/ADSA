# Badge

A small, static label for the state of the thing beside it: active, overdue, draft.
It is not a button and not a filter — a badge a person can click is the wrong
component, and the answer is `Button` with `size="sm"`.

## Import

```tsx
import { Badge } from "@acme/ui/badge";
```

## Usage

```tsx
<Badge tone="success">Active</Badge>
```

The tone carries meaning, so it is never decorative: `success` for a good end state,
`warning` for something that needs attention soon, `danger` for a failure a person
must act on, `neutral` for everything else.

## Notes

- Colour is never the only signal: the word inside the badge says the same thing the
  tone does, which is why there is no icon-only badge.
- A row of more than three badges is a table column, not a row of badges.
